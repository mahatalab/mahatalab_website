# Mahata Lab Website (public version)

Static site — no build step, no server, **no editing interface**.

## View locally
Double-click `index.html`.

## Deploy on GitHub Pages
1. Create a repository and upload everything in this folder (keep `.nojekyll`).
2. Settings -> Pages -> deploy from branch `main`, folder `/ (root)`.

## Editing content
Open `content/site.js` in any text editor (Notepad, VS Code) — instructions are at the top of that file.
Save, then upload/replace that file in the repository (GitHub -> file -> pencil icon -> Commit changes).
New pictures go in `assets/uploads/` (or `assets/team/`).

## Folder guide
`index.html` shell | `css/style.css` design | `js/app.js` page builder | `content/site.js` all text | `assets/` pictures
